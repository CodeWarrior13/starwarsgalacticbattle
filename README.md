# Turn-Based Star Wars Card Game

This repository currently includes a standalone to-do list application with browser local storage.

## Run locally

Open `index.html` in a modern browser. Tasks are saved automatically in `localStorage`, so they remain available when you return to the page in the same browser.

## Features

- Add, complete, and delete tasks
- Filter by all, active, or completed tasks
- Clear completed tasks or all tasks
- Responsive layout
- Persistent browser storage
